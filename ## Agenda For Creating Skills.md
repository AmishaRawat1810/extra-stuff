## Agenda For Creating Skills

- Implementation User story [ Orchestrator for end-to-end issue implementation ]
  - Phase 0: Issue Context [ fetch, understand, ask questions, validate
    assumptions, explicit about breakdowns/errors while fetching issues]
  - Phase 1: Story Planning [ collaborative planning on implementation, ask
    question until explicit "Agreed", put the plan in
    'docs/<issue number>/plan.md' when it gets confirmed ]
  - Phase 2: Task Creation [ Breakdown of the plan into tasks [ stick to plan
    context for it ], template [plan, description, risks, dependencies,
    acceptance criteria ] , validate the sub-tasks, ask if further breakdown
    required ]
  - Phase 3: Task Implementation [ Implement the task and test for all
    acceptance criteria , explicitly tell about error regarding the failed
    tests, do not move to next task until all tests passes and user explicitly
    tell "next", before moving to the next task ask user explicitly if they want
    any modification in the implementation plan for that particular task ]
  - Phase 4: Wrap Up [ only occurs after all tasks are completed, handled in the
    orchestrator #Implementation User Story ]## Agenda For Creating Skills
