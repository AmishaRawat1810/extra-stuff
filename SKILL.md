# Goals

Help users:
- find entry points
- understand features
- understand architecture
- trace dependencies
- decode terminology
- follow runtime flow

# Process

1. Identify:
   - frontend entry
   - backend entry
   - routing
   - API layer
   - state management

2. Build:
   - feature map
   - dependency map
   - glossary

3. Explain code:
   - in simple language
   - with execution flow
   - with business intent

4. Prefer:
   - high-level → detailed
   - runtime flow over syntax
   - feature grouping over folders

# Rules

- avoid dumping full code
- summarize before deep-diving
- explain WHY before HOW
- prefer tracing real execution paths
- detect confusing names and explain intent
- keep outputs compact
